# Watto — Your Little Task Catcher

As a ceramic artist, digital creator, and aspiring web developer, my weeks can get pretty chaotic. Between creating, learning, and working on different projects, keeping everything organized isn't always easy.

That's why I created Watto: a little task catcher designed to bring some order to the chaos and make weekly planning more fun. Create tasks, sort them into categories, and catch them one by one!

Because organizing your week can be fun, too.

## Features

- Organize your weekly tasks
- Create and categorize tasks
- Drag and drop tasks into different days
- Mark tasks as completed
- Save tasks in your browser

## Built With

- HTML
- CSS
- JavaScript
- Local Storage

## Getting Started

Open `index.html` in your browser to start using Watto.

## Note

Tasks are saved locally in your browser and do not automatically sync across devices.

Made with curiosity and a little bit of chaos.
